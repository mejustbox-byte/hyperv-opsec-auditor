# Проверки безопасности и лабораторные gates

## Автономные проверки

Тесты проверяют строгую схему, дополнительные поля/типы, Unicode/UTF-8, дублирующие ключи, нечисловые JSON константы, ограничения размера/глубины, свежесть, применимость, неизвестные значения, исключения, четыре результата и коды CLI. Проверяются экранирование Markdown, отказ от перезаписи и ссылки/вывод в пределах доступной ОС. На Windows тест символьной ссылки POSIX пропускается; остальные проверки не требуют Hyper-V. Пакетные проверки отдельно подтверждают отсутствие runtime зависимостей, суммы, лицензии, повторную сборку и установку. Поиск секретов эвристический, не абсолютная гарантия.

В [VERIFICATION](VERIFICATION.md) различаются результаты текущего checkout, GitHub CI, опубликованные файлы и облачный draft. Не переносите число пройденных тестов в другой commit без запуска. Внешний pentest, fuzzing кампании, формальная верификация, независимый supply-chain/CVE аудит и проверка гонок Windows ФС отдельно не выполнены; тесты не являются доказательством отсутствия всех ошибок.

## Реальные платформенные gates — НЕ ВЫПОЛНЕНО

| Gate | Нужные evidence/приемка | Причина ограничения |
|---|---|---|
| Host/management plane/WinRM | Проверенные настройки, доступность listener и запрещенный доступ по утвержденному плану | Нет отдельного Windows Server стенда и live сборщика |
| Администраторы/ACL | Проверка эффективных прав, групп, делегирования и аварийного доступа | JSON фиксирует утверждения владельца |
| VM/vSwitch/VLAN | Разрешенные и запрещенные потоки, сохранение изоляции после перезапуска | Синтетические boolean не проверяют сеть |
| Secure Boot/vTPM | Поддерживаемая версия хоста, generation/гость/template, состояние ключей | Поддержка зависит от реальной конфигурации |
| Shielded VM/HGS | Аттестация, отказ недоверенному хосту, восстановление ключей | Нужна поддерживаемая защищенная инфраструктура |
| VHDX/checkpoints/backup | Эффективные ACL, независимость/неизменяемость копий и ограничения удаления | Нужны реальные носители и учетные границы |
| Журналы | События теста, централизованная доставка, retention и защита удаления | Внешний приемник не реализован/не испытан |
| Восстановление | Чистое изолированное восстановление, целостность VM, RPO/RTO и протокол | Не исполнялось на живой платформе |

Порядок, отрицательные сценарии, критерии и запрет реального вредоносного ПО описаны в [LOCAL-PC](LOCAL-PC.md) и [docs/lab](docs/lab.md). Для выпуска стабильной версии нужны приватные обезличенные протоколы приемки каждой применимой конфигурации и утвержденное решение по остаточным рискам. До этого 0.1.0a2 остается prerelease. Недоступный gate нельзя заменить синтетическим pass или объявить несущественным без обоснования владельца.
