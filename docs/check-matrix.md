# Матрица автономных правил и платформенной приемки

Все семейства реализованы и покрыты синтетическими тестами. Реальные Windows Hyper-V/HGS и восстановление НЕ ПРОВЕРЯЛИСЬ.

| ID | Данные / базовая политика | Применимость / неизвестность | Приемка Windows |
|---|---|---|---|
| HV-01 | Роль, поддерживаемая конфигурация/сборка, актуальные обновления | Отсутствующие/ошибочные/устаревшие данные → `unknown` | Поддержка конкретной сборки/оборудования |
| HV-02 | Проверенные эффективные права, фактические администраторы входят в утвержденные, раздельные учетные записи/сеть | Нет проверки прав — нет `pass` | Вложенные группы AD, делегирование, PAW, права |
| HV-03 | HTTPS, сертификат, область межсетевого экрана, ограничение делегирования; Basic/незашифрованный доступ выключены | Выключен → `not_run` | Слушатели, эффективные политики, просроченный сертификат |
| HV-04 | Проверенный полный перечень адаптеров, разрешенные VLAN/коммутаторы/транки/SR-IOV | Неполнота → `unknown`; нет адаптеров → `not_run` | Внешние/внутренние/частные коммутаторы, транки, фактическая изоляция |
| HV-05 | Поддерживаемая Gen2, обязательный Secure Boot включен, шаблон утвержден | Gen1/неподдерживаемость/необязательность → `not_run` | Поддерживаемая гостевая ОС, шаблон доверия, загрузка |
| HV-06 | Обязательный vTPM; Shielded VM дополнительно требует защиту ключа/HGS | Одного vTPM недостаточно; нет профиля → `unknown` | Доверие HGS, восстановление ключей, поддержка VM |
| HV-07 | Полное хранилище, проверенные ACL без неутвержденных субъектов, требуемое шифрование | Нет проверки эффективных прав → `unknown` | VHDX/AVHDX/конфигурации/SMB ACL, шифрование |
| HV-08 | Независимая неизменяемая/автономная копия, отдельная учетная запись, не только контрольные точки | Нет сведений поставщика → `unknown` | Реальные права и неизменяемость копий |
| HV-09 | Аудит, внешняя доставка, защита от подмены, достаточный срок хранения | Нет подтверждения доставки → `unknown` | Каналы событий, получатель, сроки, переполнение |
| HV-10 | Свежее датированное восстановление, инструкция/целостность/изоляция/проверяющий, RPO/RTO в целях | Нет свежего испытания → `unknown` | Изолированное восстановление без вредоносных программ |

`pass` требует всех необходимых фактов. Известное нарушение преобладает над недостатком иных фактов; устаревшие данные не используются. Неполный перечень VM дает отдельный `unknown` вместе с результатами известных VM. Лимиты актуальности и версии включены в JSON. Политика задается ожидаемыми/разрешенными/обязательными полями владельца, не внешним исполняемым файлом. Полное покрытие инфраструктуры не заявляется.
