# Модель угроз

## Активы и границы доверия

Активы: ОС хоста, плоскость управления, административные учетные записи, VM/гостевые данные, vSwitch/VLAN, VHDX/контрольные точки, защитники ключей/HGS, резервные копии и журналы. Границы: рабочая станция администратора → WinRM/хост; хост → VM; VM → виртуальная сеть; хост → хранилище/копии; хост → HGS; сборщик → автономный обработчик → получатель отчета.

## Противники и сценарии

| Сценарий | Последствие | Данные / контроль | Ограничение |
|---|---|---|---|
| Компрометация администратора или WinRM | Управление всеми VM | Группы, делегирование, аутентификация/TLS, межсетевой экран, доверенные рабочие станции | Без внешних свидетельств MFA/PAW неизвестны |
| VM пересекает сетевую границу | Боковое перемещение | Коммутаторы/VLAN/транки/SR-IOV и утвержденная топология | Конфигурация не доказывает фильтрацию при выполнении |
| Подмена загрузки/кража диска VM | Раскрытие данных | Gen2 Secure Boot, vTPM, Shielded VM/защита ключей | Компрометация хоста ограничивает доверие |
| Программа-вымогатель получает права на хранилище/копии | Потеря VM и восстановления | ACL, отдельные учетные записи, неизменяемые/автономные копии, учебное восстановление | Контрольная точка и наличие копии не доказывают восстановление |
| Удаление журналов/подмена данных | Ложный `pass` | Хранение, внешний сбор, происхождение и актуальность | Захваченный хост может лгать сборщику |
| Утечка отчета/примера | Раскрытие инфраструктуры | Обезличивание, минимизация, контроль доступа | Отчеты конфиденциальны |
| Вредоносный ввод | Ошибка обработчика/инъекция | Схема, лимиты, отсутствие `eval` и команд из данных | Тесты ограничены синтетическими входами |

## Предположения и остаточный риск

Владелец разрешает аудит, ожидаемая топология и политика известны, лаборатория изолирована. API чтения могут создавать события аудита и нагрузку. Целостность данных компрометированного хоста не гарантируется. Аудитор не является тестом на проникновение, защитой от программ-вымогателей или сертификатом соответствия. Отказ доступа не обходится и обозначается `unknown`.

## Защита автономного MVP

Недоверенный локальный JSON ограничен 2 MiB. Повторные ключи, неизвестные поля, неограниченные/нечисловые значения, неправильные типы/даты и повторные идентификаторы объектов запрещены. В обработчике нет сетевых вызовов, `eval`, `subprocess` и извлечения архивов. Идентификаторы — короткие псевдонимы. Markdown экранируется; ошибки не печатают входные значения. Выходные файлы не перезаписываются, включая символические ссылки; stdout требует защищенного хранения.

Владелец может предоставить ложные ожидаемые/утвержденные поля. Схема подтверждает структуру, а не истинность. `collected_at` и дата учебного восстановления не проверяются криптографически. JSON отчеты остаются конфиденциальными даже с псевдонимами; полный входной документ в них не включается.
