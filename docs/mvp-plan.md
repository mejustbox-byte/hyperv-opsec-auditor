# План и границы первого MVP

## Реализуемый сквозной сценарий

1. Публичная документация требований, угроз, архитектуры и ADR.
2. Схема JSON 1.0, строгий автономный прием данных и три синтетических сценария.
3. CLI `validate`/`rules`/`audit`, десять семейств правил, отчеты JSON/Markdown и безопасная запись.
4. Модульные тесты каждого семейства и статусов, интеграционные тесты CLI, некорректный ввод и установка пакета.
5. Закрепленные с хешами зависимости, автономный CI Linux/Windows, wheel/sdist и контрольные суммы.
6. PR и слияние после доступных проверок; предварительный выпуск с явными ограничениями.
7. Русская документация, пользовательские тексты и шаблоны; версия пакета `0.1.0a2` и тег `v0.1.0a2` без перемещения `v0.1.0a1`.

## Отложено до лабораторной приемки

Сборщик PowerShell 5.1, профили поддерживаемых версий Microsoft, вычисление эффективных групп/ACL, интеграция WinRM, изоляция при выполнении, аттестация HGS, резервное копирование поставщиков и подписанный протокол восстановления. Приемка включает сравнение состояния до/после, поддерживаемые аппаратные/вложенные конфигурации, отказ доступа и восстановление без вредоносных программ. Продукт не исправляет настройки.

## Условие выпуска

Доступные автономные проверки и установка пакета должны пройти; секреты не допускаются. Реальные Hyper-V и восстановление остаются НЕ ВЫПОЛНЕНЫ и требуют предварительного выпуска. Локальные тесты не равны удаленному CI. Описание выпуска фиксирует фактические результаты; недоступные операции GitHub блокируют соответствующую часть публикации.
