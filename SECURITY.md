# Security policy

This alpha evaluates supplied evidence offline and does not connect to infrastructure. It is not a security certification or a ransomware protection tool. No live Windows Hyper-V/HGS/recovery validation has been performed.

Do not submit production evidence, credentials, keys, real topology or sensitive reports in public issues/PRs. Use the repository Security tab private vulnerability reporting if available; if unavailable, request a private contact without posting exploit details or secret data. No private reporting channel is promised by this file.

Input is limited to strict schema-valid JSON with pseudonymous identifiers. Reports remain sensitive. Remediation is advisory text only. A compromised evidence source or malicious policy owner can produce misleading results; signatures and independent attestation are not implemented. See the threat model and laboratory procedure before production use.
