# Сведения о выпуске 0.1.0a2

## Изменение

Новый предварительный выпуск Hyper-V `v0.1.0a2`, пакет `0.1.0a2`: русские документы, правила, схема, справка, ошибки, рекомендации и отчеты UTF-8; полный набор проектных документов и русские шаблоны; стандартный MIT LICENSE с русским переводом, метаданные и обе лицензии в пакетах; документы по хранению данных, цепочке поставки и проверкам безопасности, AGENTS.md. Ключи JSON, идентификаторы и логика оценки сохранены. Четыре дополнительных теста проверяют локализацию и кодировку. Старый v0.1.0a1 остается доступен с прежним тегом и файлами.

## Установка и использование

Python >=3.12. Скачайте wheel и SHA256SUMS из выпуска, сравните контрольную сумму, затем установите без индекса: `python -m pip install --no-index --no-deps hyperv_opsec_auditor-0.1.0a2-py3-none-any.whl` в выбранной venv. Сторонних зависимостей выполнения нет. Команда вымышленного примера: `hyperv-opsec-auditor audit healthy.json --as-of 2026-10-09T00:00:00Z --format json`. [Полные POSIX/Windows/source команды и удаление](INSTALL.md).

## Проверки и файлы

Локально: 42 теста и 96% покрытия. До публикации обязательны CI Ubuntu/Windows, сборка wheel/sdist, чистая установка, внутренние ссылки, поиск секретов и контрольные суммы. В описании GitHub Release workflow фиксирует точный commit и ссылку на фактический запуск. После публикации файлы скачиваются, суммы сверяются и опубликованный wheel устанавливается в чистую среду. Локальный результат не подменяет эти проверки.

Файлы: универсальный wheel, исходный sdist, JSON схема, healthy/unsafe/partial, примеры JSON/Markdown, RELEASE_NOTES.md, VALIDATION.md и SHA256SUMS. [История](CHANGELOG.md), [контроль](RELEASE-CHECKLIST.md), [протокол](VERIFICATION.md).

## НЕ ВЫПОЛНЕНО

Реальный Windows Server Hyper-V, AD/WinRM/эффективные ACL, VM/vSwitch/VLAN изоляция, поддерживаемые гости Secure Boot, vTPM/Shielded VM/HGS/ключи, неизменяемость резервных копий и восстановление после программ-вымогателей с RPO/RTO. Сборщик Windows не реализован. CI Windows тестирует только автономный Python. Восстановление новой задачи из опубликованного снимка облака отдельно не проверено. Выпуск остается предварительным; процедура стенда — [LOCAL-PC](LOCAL-PC.md).
