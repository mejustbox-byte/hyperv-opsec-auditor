# Зависимости, лицензии и целостность выпуска

## Инвентаризация

Пакет выполнения не имеет сторонних зависимостей. Стандартная библиотека принадлежит установленному Python; Python >=3.12, в CI 3.12. ОС и Python исправляются отдельно. Проект MIT: [исходный текст](LICENSE), [русское пояснение](LICENSE.ru.md). Зависимости разработки не включаются в wheel как собственный код; установка инструментов закреплена версиями и SHA256 в requirements-dev.lock.

Инвентаризация проверена на установленных **закрепленных** пакетах; для packaging/colorama/wheel классификаторы уточняются текстами лицензий поставщиков. Это декларации upstream, не полный юридический аудит бинарных транзитивных компонентов, SBOM или проверка отсутствия всех известных CVE. rpds-py содержит бинарное расширение инструмента проверки схемы, но в runtime аудитора не требуется. CI actions закреплены полными commit SHA, смотрите фактические workflow; их среда и внешние зависимости все равно остаются частью доверия поставки.

## Контроли обновления

Устанавливайте инструменты через `--require-hashes --only-binary=:all:`; не отключайте TLS, не подменяйте ожидаемые hashes и не используйте неподтвержденный индекс. Обновление lock — отдельный review: проверить происхождение, лицензию, изменения транзитивных зависимостей, совместимость Python/Windows и все автономные/package проверки. Автоматическое обновление зависимостей приложением отсутствует. Поиск шаблонов секретов не является полноценным аудитом зависимостей; внешнее сканирование CVE отдельно НЕ ВЫПОЛНЕНО.

## Целостность

`tools/build_release.py` строит wheel/sdist закрепленными инструментами, копирует синтетические примеры/схему/русские сведения, считает SHA256SUMS. `tools/package_smoke.py` проверяет каждую сумму, MIT License-Expression, оба файла лицензии в wheel и sdist, полный набор корневых документов, пересборку sdist и чистую установку wheel без runtime зависимостей. Эти проверки повторяются в CI.

Release workflow работает с точным main SHA и краткоживущим GitHub Actions token только для публикации; реальные credentials в файлах не хранятся. Существующий tag нельзя передвигать. Сопоставьте tag → merge commit → успешные CI и release run; затем скачайте assets, проверьте суммы и установку. SHA256SUMS из того же скомпрометированного источника не защищает от подмены издателем; подписей издателя и независимых attestation нет. [RELEASE-CHECKLIST](RELEASE-CHECKLIST.md) содержит операционные шаги, [VERIFICATION](VERIFICATION.md) — границы доказательств.
