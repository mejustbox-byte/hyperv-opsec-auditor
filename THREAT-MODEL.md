# Угрозы, контроли и остаточный риск

## Активы и доверие

Защищаемые активы — хост Hyper-V, плоскость управления, VM/диски, виртуальная сеть, ключи/HGS, резервные копии и журналы. Сам аудитор обрабатывает конфиденциальный экспорт. Источник и утвержденная политика принадлежат владельцу; их достоверность не выводится из структуры JSON. Компрометированный хост способен предоставить ложные данные.

| Угроза | Реальный контроль MVP | Остаточный риск / следующая проверка |
|---|---|---|
| Вредоносный JSON/инъекция | Лимиты, строгая схема, отсутствие eval/команд/сетевого доступа | Истинность входных фактов не подтверждается |
| Неполные/устаревшие данные как успех | Явные unknown/not_run, свежесть, ошибки сбора | Дата сбора и внешняя аттестация не подписаны |
| Утечка сведений | Псевдонимы, ошибки без значений, нет полного входа в отчете | Псевдонимы не гарантируют анонимность; stdout и JSON чувствительны |
| Перезапись входа/отчета | O_EXCL, новые пути, POSIX 0600 | ACL Windows контролирует оператор; сбой диска может оставить неполный файл |
| Ложная защита Shielded VM | Отдельные факты vTPM, shielded, ключа/HGS и поддержка профиля | Реальная HGS аттестация НЕ ВЫПОЛНЕНА |
| Ложная готовность восстановления | Датированный протокол, целостность, изоляция, RPO/RTO | Наличие копии не доказывает восстановление; реальный стенд НЕ ПРОВЕРЕН |
| Подмена пакета | TLS/хеши зависимостей, SHA256SUMS выпуска | Суммы не заменяют подпись издателя |

Аудитор не является тестом на проникновение или сертификатом соответствия. Он не обходит отказ доступа и не выполняет рекомендации. Будущий сборщик должен иметь перечень разрешенных операций чтения и проверку до/после; само чтение способно создавать события и нагрузку. [Подробная модель](docs/threat-model.md), [процедура сообщений](SECURITY.md), [лаборатория](LOCAL-PC.md).

## Границы доверия обработки

| Граница | Ответственность и контроль | Остаточный риск |
|---|---|---|
| Инфраструктура → ручной экспорт | Владелец разрешает чтение и сверяет факты, сборщик не реализован | Компрометированный источник способен лгать |
| Экспорт → JSON валидатор | Лимиты/строгая схема/псевдонимы | Схема не аттестует источник и не ищет все секреты |
| Политика → правила | Явные утвержденные/ожидаемые значения владельца | Ложно разрешающая политика дает ложное ощущение защиты |
| Правила → отчет → получатель | Экранирование, новые файлы, контроль доступа владельцем | stdout/JSON и копии чувствительны, retention ручная |
| GitHub/инструменты → установленный пакет | Закрепленные версии/hashes, CI, tag/commit и суммы assets | Нет независимых подписей/аттестации издателя |

[Хранение и retention](SECURITY-DATA.md), [поставка и лицензии](SUPPLY-CHAIN.md), [security проверки/gates](SECURITY-TESTING.md). Эти обязанности не превращают автономные результаты в подтвержденную аттестацию платформы.
