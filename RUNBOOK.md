# Эксплуатация и разбор ошибок

## Предварительные условия

Установлен проверенный wheel; владелец разрешил область и подготовил обезличенные данные вне публичной копии. Утверждены ожидаемые поля политики, дата и источники. Отдельно выполненные внешние проверки не подменяются вымышленными значениями.

## Запуск и приватные отчеты

Выберите приватный каталог вне репозитория с ограниченными ACL. Выполните `hyperv-opsec-auditor validate /private/evidence.json`, затем `hyperv-opsec-auditor audit /private/evidence.json --format json --output /private/new-report.json --fail-on incomplete`. Эти пути — пример, каталог создается владельцем заранее. Для реальных данных `--as-of` по умолчанию использует текущее UTC; фиксированная дата синтетического примера не применяется.

Сохраните версию, параметры, дату оценки, версию политики и источник. JSON и Markdown с одинаковым `--as-of` дают одинаковую оценку. Никакие рекомендации не выполняются автоматически. Даже псевдонимизированный отчет конфиденциален; stdout не защищает данные. Файлы POSIX имеют 0600, Windows использует ACL каталога. Срок хранения определяет владелец; продукт не удаляет отчеты.

## Состояния и ошибки

| Наблюдение | Действие оператора |
|---|---|
| Код 2 при чтении/схеме | Проверить UTF-8, размер, обязательные поля, даты, типы, дубликаты; не публиковать реальные значения ошибки |
| Код 2 при записи | Проверить доступ, свободное место и новый путь; неполный файл не использовать |
| Код 1 | Изучить summary/findings: fail или неполнота по --fail-on; это не сбой запуска |
| unknown | Дополнить отсутствующие/ошибочные/устаревшие данные отдельно разрешенным способом |
| not_run | Проверить исключение, сбор раздела, перечень объектов и применимость; не считать pass |
| pass | Подтверждено только соответствие предоставленных фактов; независимая проверка нужна отдельно |

Не обходите ACL, не включайте WinRM, не повышайте права ради заполнения отчета. Поддерживаемость профилей, реальная сеть, AD/хранилище, HGS и копии проверяются на стенде.

## Обновление и остановка

Работа завершается после команды: служб и портов нет. Сохраните старый пакет/суммы/отчет и параметры; новый wheel установите в новую venv и повторите синтетический тест, затем проверьте совместимость реальных данных. При регрессии используйте сохраненную старую среду, не меняйте теги. Удаление описано в [INSTALL](INSTALL.md). Приватные отчеты очищаются владельцем по его правилам, не автоматически. [Контракт](CORE-CONTRACT.md), [безопасность](SECURITY.md).
